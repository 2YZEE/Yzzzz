# مصدر مركز المذاكرة

هذا مجلد التطوير لمشروع React + Vite. ابدأ بـ `npm ci` ثم `npm run dev`.

ملف `index.html` في هذا المجلد مخصص للتطوير. ملفات الإنتاج في جذر الحزمة هي التي تخدمها GitHub Pages.

## نشر تحديث

1. من داخل `source/` شغّل `npm ci` ثم `npm run build`؛ ينتج الإصدار في `docs/`.
2. انسخ محتويات `docs/` إلى جذر مستودع GitHub بجانب `source/`، ثم ادفع التحديث.
3. اضبط Pages على الفرع `main` والمجلد `/ (root)`.
