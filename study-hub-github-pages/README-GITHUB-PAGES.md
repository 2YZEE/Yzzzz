# مركز المذاكرة — حزمة GitHub Pages

## رفع الموقع

1. فك ضغط هذه الحزمة على جهازك.
2. ارفع **كل محتويات الحزمة** إلى جذر مستودع GitHub، وليس ملف ZIP نفسه. يجب أن يظهر `index.html` مباشرة بجانب `assets/` و`banks/`.
3. في المستودع افتح **Settings → Pages**، واختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
4. انتظر اكتمال النشر من قسم Pages أو Actions.

## كود React

المصدر الكامل موجود في `source/` ويتضمن React وVite وبنوك الأسئلة. ملفات الموقع الجاهزة للنشر موجودة في جذر هذه الحزمة. عند تحديث الكود، راجع `source/README.md`.
